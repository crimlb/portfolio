
# 🚀 Portfolio React - Cristina Buffone

Benvenuto nel repository del mio portfolio personale, una Single Page Application sviluppata con React e progettata per raccontare il mio percorso come Frontend Developer attraverso progetti, competenze e formazione.

L'obiettivo del progetto è creare un'esperienza moderna, dinamica e coinvolgente che unisca design, performance e interattività.

---

## ✨ Caratteristiche Principali

* 🎨 Interfaccia moderna e completamente responsive
* 🚀 Sviluppato con React 19 e Vite 8
* 🌊 Effetti Parallax personalizzati
* 🎭 Animazioni fluide con Framer Motion
* 📱 Ottimizzato per desktop, tablet e smartphone
* 🖼️ Showcase interattivo dei progetti realizzati
* 📧 Sistema di contatto integrato tramite EmailJS
* 🎯 Focus su User Experience e performance

---

## 🛠️ Tecnologie Utilizzate

### Frontend

## 🚀 Avvio del Progetto

### Clonazione Repository

```bash
git clone https://github.com/USERNAME/NOME-REPOSITORY.git
```

### Installazione Dipendenze

```bash
npm install
```

### Avvio Ambiente di Sviluppo

```bash
npm run dev
```
